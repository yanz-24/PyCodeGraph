About

PyCodeGraph is a free, interactive tool for visualizing the structure of Python code. Upload a Python script or paste your code to explore its functions, imports, and package dependencies through an interactive network. The tool was vibe coded as a lightweight, accessible way to understand how different parts of a Python script relate to one another, without installing additional software.

Understanding the Node Types

Click an orange or green node to see its import status: referenced, potentially unused, or unresolved. Floating nodes alone do not prove an import is unused. The network organizes code elements into three categories: Local Functions (Blue): Functions defined within your Python code. Imported Symbols (Orange): Functions, classes, and other symbols imported from external modules. Packages (Green): Modules and packages that provide the imported symbols.

Privacy

All analysis runs locally in your browser. Your code is not uploaded to a server.

Controls

Scroll to zoom at the cursor. Drag empty space to pan. Drag a node to move its immediate neighbors by 45% and second-degree neighbors by 15%. Click a node to inspect its relationships.

limitations

This offline analyzer uses a lightweight JavaScript source scanner, not Python's full AST. It recognizes common def, class, import, from ... import, and explicit calls and non-call references (including attributes). The graph uses three node categories: local functions, imported symbols, and packages. Dynamic imports, alias shadowing, star imports, and ambiguous or indirect references may be missed or unresolved. Import statuses are best-effort, not proof of unused code. The source code is never executed or uploaded.
